## How to upgrade Unicode files

The updates are yearly, generally in oct/nov.

### utf8proc

```
cd any_directory
git clone https://github.com/JuliaLang/utf8proc
```

#### Replace the existing files in `Unicode/utf8proc` by the new files from Github.

#### Review `Unicode/UnicodeServices.cpp`

`grapheme_break_simple` is a duplicate; update it if needed whenever utf8proc is updated.

`grapheme_break_extended` is a duplicate; update it if needed whenever utf8proc is updated.

Check whether the enum tables need to be updated (if new values have been added to `utf8proc.h`).

```
UnicodeServices.cpp                  utf8proc.h
-------------------                  ----------
General_Category[]                   utf8proc_category_t
Canonical_Combining_Class[]          no enum type, it's an integer 0..254. See if PropertyValueAliases.txt contains new short/long names.
Bidirectional_Character_Types[]      utf8proc_bidi_class_t
Compatibility_Formatting_Tags[]      utf8proc_decomp_type_t
Indic_Conjunct_Break[]               utf8proc_indic_conjunct_break_t
East_Asian_Width[]                   listed, but not supported by utf8proc (so far)
Grapheme_Cluster_Break[]             utf8proc_boundclass_t
```

### unicode-width

`Unicode/unicode-width` is a port of the Rust crate `unicode-width`to C++.

```
cd any_directory
git clone https://github.com/unicode-rs/unicode-width.git
```

Some files are generated by the `unicode-cpp.py` Python script from the Unicode
Character Database at https://www.unicode.org/Public/UCD/latest/ucd/. The UCD
files are automatically downloaded.


```
Rust crate                      C++ port
----------                      --------
scripts                         scripts
    unicode.py                      unicode-cpp.py
src                             src-cpp
    gen                             gen
        lookup.rs                       lookup.cpp, lookup.hpp
        props.rs                        props.cpp
        tables_test.rs                  tables_test.cpp
        tables.rs                       tables.cpp
        width_infos.rs                  width_info.cpp
    lib.rs                      lib.txt (no code, just documentation)
    lookup.rs                   lookup.cpp, lookup.hpp
    props.rs                    props.cpp, props.hpp
    test.rs                     N/A
    width_info.rs               width_info.hpp
```

Check the changes applied to the non-generated Rust files and apply the
corresponding changes to the C++ files.

Check the changes applied to `scripts/unicode.py` and apply the corresponding
changes to `scripts/unicode-cpp.py`.

Generate the gen/files:
```
cd scripts
python3 unicode-cpp.py
```

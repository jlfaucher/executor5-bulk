Why '\x00'.width = None?
--------------------------------------------------------------------------------

It's not clear why they decided to return
'\x00'.width = None
"\0".width = 1
See the laconic answer "this is intentional, and according to the spec".
in https://github.com/unicode-rs/unicode-width/issues/87
This answer does not explain why returning None for control characters.

ooRexx has only a String type, so
.RexxUnicodeServices~utf8StringWidth('00'x) = 1

This logic could be implemented in ooRexx by supporting
.RexxUnicodeServices~codepointCharWidth2( codepoint, eastAsianContext = .false )
fn single_char_width_generic<const IS_CJK: bool>(c: char) -> Option<usize> {
    if c < '\u{7F}' {
        if c >= '\u{20}' {
            // U+0020 to U+007F (exclusive) are single-width ASCII codepoints
            Some(1)
        } else {
            // U+0000 to U+0020 (exclusive) are control codes
            None
        }
    } else if c >= '\u{A0}' {
        // No characters >= U+00A0 are control codes, so we can consult the lookup tables
        Some(lookup_width_generic::<IS_CJK>(c).0.into())
    } else {
        // U+007F to U+00A0 (exclusive) are control codes
        None
    }
}

Tables of Rust's byte-packed [u8; 3]
--------------------------------------------------------------------------------

The C++ representation is less compact than Rust's

> Rust's byte-packed [u8; 3] codepoint-range pairs became a plain struct CodepointRange { uint32_t lo, hi; } —
  same data, simpler representation.

but is still quite acceptable:

    // A closed codepoint range [lo, hi].
    struct CodepointRange {
        std::uint32_t lo;
        std::uint32_t hi;
    };

    | Representation       | Per range |
    | -------------------- | --------: |
    | Rust `[u8; 3]` pairs |   6 bytes |
    | C++ `uint32_t` pairs |   8 bytes |
    | Difference           |  +2 bytes |

    sizeof CodepointRange NON_TRANSPARENT_ZERO_WIDTHS[71] = 568 (+142 bytes)
    sizeof CodepointRange SOLIDUS_TRANSPARENT[208] = 1664       (+416 bytes)
